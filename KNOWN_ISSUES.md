# Known limitations and remaining work

1. **No completed browser/device acceptance test.** The browser tool rejected the local URL with `ERR_BLOCKED_BY_CLIENT`. This is an environment limitation, not evidence that the game has no visual bugs. No Windows/Android FPS, touch layout, audio, screenshot or GPU stability results are claimed.
2. **World art is still an alpha.** Four new districts use compact procedural corridors, buildings, vegetation, shelters and biome details. They need authored landmarks, richer towns, mountain/hairpin terrain, wildlife/crowd detail and visual review. Original Kozhikode core geometry remains resident when visiting other districts; generated additions unload.
3. **Bus scope is basic.** Nine configurations now include a shorter six-seat minibus and longer coach geometry. Visual acceptance of these variants and the entire requested garage catalogue (curtains, wheels, dashboard accessories, mirror/board styles) are incomplete.
4. **Traffic rules are partial.** Current warnings cover red signals, prolonged wrong lane, severe speeding and abrupt heavy impacts. Full one-way routing, richer junction priority, skipped-stop penalties and smooth-braking/passenger-delivery rating bonuses remain to be developed. Impact detection now uses confirmed physics collisions; driving-rule tuning still needs playtests.
5. **Activity polish remains.** Boats are simple bounded lake movement; cycling uses lightweight movement. Photo/audio/boat visuals still need browser testing. Most wildlife discoveries are markers, not detailed animated wildlife. Ambient audio and AI-bus/crowd expansion are incomplete.
6. **Moderation requires an operator.** Filtering is a small English word list, not comprehensive Malayalam/transliteration moderation. Report evidence is limited to the last 80 room messages. There is no moderator dashboard yet. The API is disabled without a server-only `MODERATOR_TOKEN` of at least 32 characters. Temporary moderator actions are restored from saved audit history; spam mutes are session-local. Data retention/review operations need configuration before public chat release.
7. **Database migrations are prepared only.** No local PostgreSQL engine was available. SQL execution/RLS/RPC integration and deployment of the updated server-only Edge Function have not been verified. Production must not run this server against the unchanged old schema.
8. **Load checks are short loopback tests.** 15 connections does not establish 15-rendered-player mobile FPS, long-session stability, packet-loss tolerance, multi-room hosting capacity or suitability for a free production instance.
9. **Initial download remains sizeable.** Babylon's bundle triggers Vite's chunk-size warning. The build succeeds; first-load behavior on slow mobile networks remains unmeasured.
10. **Identity remains browser-based.** Same name on another browser/device is a different identity. Clearing site data loses the local identity token. Solo practice is temporary. Rooms and active buses are in memory and reset on server restart; saved player progress persists.

These are release blockers/unfinished scope, not a finished V2 claim. No production update has been made.
